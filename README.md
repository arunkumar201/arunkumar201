## What I do

I build and ship production AI systems: multi-agent platforms, retrieval-augmented generation (RAG) pipelines, and the backends and interfaces around them. I care about the parts that decide whether an LLM app survives in production: evaluation, memory, cost, latency, and reliable deployment.

- Multi-agent harnesses that run across WhatsApp, Telegram, and web channels, with pluggable domains and tool use
- RAG chatbots with long-term memory, vector search, and knowledge-base-only answers
- AI content and automation products: image, video, and voice generation, outbound sales and job-search agents
- Full-stack delivery from API to UI, so the model ships as a product and not just a notebook
